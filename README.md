# Customer Sentiment Analysis

## Project Overview

Customer Sentiment Analysis is a data analytics and NLP project that analyzes customer reviews to identify whether the feedback is Positive, Negative, or Neutral.

The project uses Python for data processing and sentiment analysis, and Power BI for interactive visualization and business insights.

## Objectives

- Analyze customer reviews and ratings
- Classify customer feedback into sentiment categories
- Calculate sentiment scores
- Identify sentiment patterns across product/service categories
- Build an interactive Power BI dashboard
- Present customer feedback insights in a business-friendly format

## Technologies Used

- Python
- Pandas
- NLTK / VADER Sentiment Analysis
- Jupyter Notebook
- Power BI
- Microsoft Excel
- GitHub

## Project Workflow

Customer Reviews
       ↓
Data Cleaning & Processing
       ↓
Sentiment Analysis using VADER
       ↓
Positive / Negative / Neutral Classification
       ↓
Sentiment Score & Rating Analysis
       ↓
Power BI Dashboard
       ↓
Business Insights

## Dashboard Features

The Power BI dashboard includes:

- Sentiment Distribution
- Sentiment by Category
- Average Sentiment Score
- Average Customer Rating
- Total Number of Reviews
- Customer Review Details
- Rating Distribution

## Project Files

- `customer_reviews.csv` — Original customer review dataset
- `customer_sentiment_analysis.csv` — Processed dataset with sentiment results
- `Customer_sentiment_Analysis.ipynb` — Python/Jupyter Notebook
- `Customer_Sentiment_Analysis.pbix` — Power BI dashboard
